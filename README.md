# Paseo Guides

社区驱动的 OpenCode 智能代理平台使用指南、教程、插件与实践心得集合。

基于 OpenCode 官方文档 (opencode.ai/docs) 整理，包含 10 篇系统化教程、社区生态指南和实践心得。

## 目录结构

```
awesome-paseo-guides/
├── site/              # 静态展示站点
│   └── index.html     # 单页应用，浏览器直接打开
├── tutorials/         # 教程系列（10 篇）
│   ├── 01-installation.md        安装与首次启动
│   ├── 02-agents-rules.md        AGENTS.md 规则配置
│   ├── 03-agents-config.md       Agent 配置与多 Agent 协作
│   ├── 04-permissions.md         权限管理系统
│   ├── 05-mcp-servers.md         MCP 服务器集成
│   ├── 06-plugins-dev.md         插件开发指南
│   ├── 07-custom-tools.md        自定义工具开发
│   ├── 08-cli-reference.md       CLI 命令完整参考
│   ├── 09-providers-models.md    Provider 与模型配置
│   └── 10-ecosystem.md           社区生态与实战组合
├── experiences/       # 实践心得
│   ├── 01-async-workflow.md
│   ├── 02-workspace-isolation.md
│   ├── 03-schedule-traps.md
│   └── 04-prompt-engineering.md
├── FAQ/               # 常见问题（社区贡献）
├── scripts/           # 工具脚本
│   └── publish-gist.mjs    Gist 发布脚本
└── docs/              # 文档
```

## 快速使用

1. 浏览器打开 `site/index.html` 查看完整介绍
2. 按 `tutorials/` 顺序阅读教程（建议 01 → 08 → 03 → 05 → 06）
3. 阅读 `experiences/` 中的实践心得
