🌟 .env 保护插件

防止 LLM 读取 .env 文件中的密钥，保护敏感配置

security hook tool.execute.before
export const EnvProtection = async ctx => ({ "tool.execute.before": async (input, output) => { if (input.tool === "read" && output.args.filePath.includes(".env")) { throw new Error("禁止读取 .env") } } })

✅ 通知插件

会话完成时通过系统通知提醒，支持 macOS 和 Linux

notification session.idle osascript
export const Notify = async ctx => ({ event: async ({ event }) => { if (event.type === "session.idle") { await $`osascript -e 'display notification "完成！"'` } } })

🔧 自定义工具

用 Zod 定义参数，LLM 自动调用你编写的工具函数

tool Zod custom-tools
import { tool from "@opencode-ai/plugin" export default tool({ description: "查询项目数据库", args: { query: tool.schema.string() }, async execute(args) { return `已执行: ${args.query}` } })

📊 Helicone 会话跟踪

Get Started

五分钟快速开始

从安装到运行第一个智能代理，只需几步

1

安装

curl -fsSL https://opencode.ai/install | bash
2

配置 Provider

opencode → /connect → 选择 OpenAI/Anthropic/DeepSeek → 粘贴 API Key
3

初始化项目

cd /path/to/project && opencode && /init
4

非交互运行（脚本化）

opencode run --auto --model anthropic/claude-sonnet-4 "分析代码结构"
5

切换 Plan 模式（只读分析）

opencode → <Tab> → 描述任务需求
