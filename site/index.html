Core Capabilities

核心能力概览

Paseo 是一套完整的远程代理管理基础设施，覆盖从任务执行到定期编排的全生命周期

⚡

智能代理 (Agents)

创建、调度、管理多代理协作。支持不同 LLM 提供商，通过 Prompt 定义任务并异步追踪结果。

MCP / CLI
📊

工作区 (Workspaces)

基于本地目录或 git worktree 的隔离环境。支持 branch-off / checkout-branch / checkout-pr 模式。

隔离执行
⏱

定时任务 (Schedules)

基于 cron 表达式的定时调度，周期性自动启动新代理执行任务，支持暂停、恢复和一次性触发。

Cron
💛

心跳提醒 (Heartbeats)

定时向你发送提醒消息，适合 PR 检查、构建监控、状态轮询等需要回传到对话的场景。

推送通知
🔌

插件系统 (Plugins)

通过 paseo.json 配置可扩展能力，自定义 workspace 脚本生命周期，集成第三方工具链。

可扩展
🔍

终端管理 (Terminals)

远程终端会话管理，支持长驻进程、实时交互，与 workspace script 深度集成。

远程 Shell

Get Started

五分钟快速开始

从安装到运行第一个智能代理，只需几步

1

创建项目

paseo project create /path/to/your/repo
2

创建工作区

paseo workspace create --isolation worktree --mode branch-off --new-branch feat-x --base main
3

运行智能代理

paseo run --provider codex/gpt-5.4 --mode full-access --workspace <id> "分析代码结构"
4

配置定时任务（可选）

paseo schedule create --cron "*/30 * * * *" "检查构建状态"
5

查看代理列表

paseo ls
