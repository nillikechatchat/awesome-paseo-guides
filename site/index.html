Get Started

五分钟快速开始

从安装到运行第一个 Agent

1

安装 Agent CLI

npm install -g @anthropic-ai/claude-code # 或 codex / copilot / opencode / pi
2

安装 Paseo CLI

npm install -g @getpaseo/cli && paseo
3

运行第一个 Agent

paseo run --provider claude "分析这个项目的结构"
4

创建工作树工作区

paseo run --new-workspace worktree --worktree-mode branch-off --new-branch feature/x --base origin/main "实现功能"
5

手机连接（可选）

paseo daemon pair # 启用中继并生成二维码
