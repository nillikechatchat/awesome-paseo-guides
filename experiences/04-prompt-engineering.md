# 实践心得 04 - 提示词工程在 Paseo 中的最佳实践

## Prompt 结构

有效的 Paseo prompt 应该包含：

```
角色定义 + 任务目标 + 输入数据 + 输出格式 + 约束条件
```

### 示例

```
你是一个代码审查专家。请审查 src/ 目录下的所有 TypeScript 文件。
重点关注：
1. 类型安全问题
2. 性能瓶颈
3. 潜在的 bug

输出格式：Markdown 表格，包含 [文件路径 | 问题类型 | 严重程度 | 建议]
不要修改文件，只输出审查报告。
```

## 迭代技巧

- 第一次任务：描述得详细一些
- 后续 follow-up：可以简短，因为代理有上下文
- 复杂任务：拆分为多个步骤，每个步骤一个 prompt

## 关键教训

1. **明确边界**：告诉代理什么该做，什么不该做
2. **指定输出格式**：方便后续处理
3. **利用 follow-up**：不追求一次性完美，迭代式优化
4. **用标签管理**：`labels` 字段标记代理类型，方便筛选
